# 解压暂存位置与无复制分卷映射

用户要求跨盘解压不要额外复制整组分卷；进一步明确允许在源目录创建符号链接。

最终行为：解压输出暂存和内嵌归档切片位于目标侧。分卷规范命名优先在源目录
的临时子目录创建相对链接；源目录不可写、不能创建或访问链接时尝试系统临时
目录的链接。两处都不可用就报错。已移除卷文件复制和 CoW/reflink 分支，所有
共享此分卷准备层的调用都不再复制分卷。创建/清理链接仍产生少量元数据 I/O。

链接访问在交给后端前检查。暂存由原有 RAII 对象清理；输出提交/回滚不变。
不宣称网络共享一定支持链接；本次没有真实 SMB/NFS/SSHFS 环境验收。

验证：

- engine 223 项单测通过，包含源目录相对链接、系统临时目录绝对链接、源卷
  保留、暂存清理及目标侧内嵌切片。
- 真实加密分卷候选组切换集成测试通过。
- 已构建 `target/debug/smartzip`，未替换全局安装程序。

这是无分卷复制和位置选择的功能验证，不是跨物理磁盘吞吐基准，也不代表 Windows
链接权限或远程服务器行为已经原生验证。
