# 分卷格式名与候选组试解压

## 请求与决策

`.7z` 格式名中的 `7` 不应参与卷号推断。分组有多个候选时，完整且结构可行的
候选应实际尝试解压；第一组成功后采用该组，停止其他尝试。

## 实现

- 数字识别排除独立的 `.7z` / `.7Z` 扩展段，保留普通文件名数字。
- 分组诊断保留完整候选的 `VolumeSet`，包括 ZIP 分卷类型与入口；不从不完整
  诊断片段猜测缺失成员或组合。没有完整可试候选时仍报告分组歧义。
- 解压沿用原有密码、编码、预算、暂存及提交流程；归档内容或密码解释失败后
  清理暂存，再尝试下一组。无需预先完整 test，也不重复解压成功组。
- 第一组成功后丢弃其他分组假设，只将获选成员登记为已处理。失败试探不增加
  最终失败计数、不单独写失败历史；全部失败才记录一次终态。
- 候选间不惩罚密码统计；先尝试现有密码，再询问新密码，新密码重新用于各组。
- 重叠分卷根按有序成员锁串行判定，互不重叠的组保持并发；等待锁时释放阶段
  资源，避免占住另一个根完成所需的配额。取消、资源、安全、清理及提交错误
  不触发换组重试。
- 7z `Headers Error` 归为归档损坏错误，与已有 test 分类保持一致，使错误组的
  加密头失败可以换组；普通后端/权限错误仍终止。

`test` / `list` 的分组路径没有改成试解压。丢弃假设不代表删除其物理文件。

## 验证

- 新增标准 `.7z` 分卷回归测试，修复前复现两个候选导致的歧义，修复后从首卷、
  中卷、尾卷均可解析；包含大小写扩展名。原有缺卷和真实歧义测试保留。
- engine 单元测试 221 项通过；archive 单元测试 77 项通过、1 项忽略。
- 真实 7z 加密分卷集成测试覆盖：首组坏、次组好；两组都好且首组胜出；全部坏；
  交互密码重新用于早先候选；资源超限不换组。验证实际产物字节与失败暂存清理。
- CLI 使用独立数据库复核：首组失败、次组成功只产生一份输出，成功历史仅一行、
  无失败行，同组重复输入被跳过；源目录没有暂存残留。
- 真实加密/未加密标准 7z 三卷的六种入口均成功解压，产物逐字节匹配。
