# 统一配置与任务策略

目标：演进现有 smartzip-config，实现“统一解析 → 固定任务策略 → 可选业务阶段 → 可解释决策”。依据用户提供的 smartzip-config-design.md、smartzip-config.proposed.toml 及当轮补充要求；源码基线为 d8724d6 加本次会话已完成的代码/测试清理。

范围：配置模型、版本化默认值、单文件选择、显式覆盖、校验、来源解释、安全编辑迁移、CLI 与引擎接线、状态与密码能力独立控制。用户随后明确 GUI 暂不接入，后续整体重做。保持直接尝试解压密码、暂存提交回滚、根输入保留，沿用深度 3 和候选 128 默认值。

验收：错误配置提前失败；false/空数组正确覆盖；禁用功能不产生对应调用或状态副作用；历史与缓存、保存与统计独立；只读与无状态不会写运行状态；配置编辑保护只读/链接/注释/并发；运行策略不随后续配置改变；既有真实后端安全路径通过回归。结果与兼容边界仅在 implement.md 记录。
