# 实施记录

## 实现

- GUI 任务中心改为状态筛选、批次分组、根归档行操作、可展开子项和文件详情。新任务配置折叠；原“暂停队列”改为准确的“暂停新任务”，不混同运行中归档的阶段暂停。
- `root_inputs` 复用 VolumeResolver，仅对已识别分卷入口去重。候选组成员集合通过传递重叠合并为一个控制组；保留全部候选入口，不提前猜测胜出组，也不丢弃可能属于另一归档的输入。配置关闭自动分卷发现时尊重该设置。
- `RootManagement` 提供本次执行的根控制和节点快照；`ManagedRecorder` 包装已有 ExecutionStateRecorder，持久状态仍由原协调器写入。根自身提交事实、子树终态和当前子项活动分别呈现；事件按实际执行入口/节点归属，不用文件名反推并发进度。
- 取消令牌对子根隔离，但显式配置的 on-error=stop 保持批次级作用。暂停在阶段边界释放已有租约；继续重新申请。提交中的操作不被暂停打断。暂停/等待交互不占准备名额，重叠组的多个候选入口不会同时派发。
- 重试创建新尝试，保留失败记录、该组所有输入及原输出目录，清空临时密码，绕过已解压历史跳过。为避免与同批次源引用及最终回收竞争，须等原批次结束后执行重试。
- 未修改 DB schema。当前根级暂停/取消请求和文件中心快照为会话内状态；不承诺重启后恢复根暂停位。已有任务级恢复继续沿用原模型，后续若要求恢复完整文件中心，需要新增根控制持久字段和恢复视图。关闭状态库时仍提供会话内控制，不伪装成可恢复提交。

- GUI 单元测试：45 通过；后续新增“失败分卷组重试保留输入/配置/历史”回归测试单独验证。
