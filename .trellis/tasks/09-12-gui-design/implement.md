## macOS 系统集成与 Finder 快速解压

系统集成独立于归档运行配置，按系统实际状态查询默认应用；仅用户点击才注册、设置默认或安装/移除服务。格式清单由 `resources/file-types.json` 供 Rust 和打包脚本共同使用。打包复制真实可执行文件并做本地 ad-hoc 签名，不替换其他应用，不修改默认程序；包标识 `org.smartzip.SmartZip`，声明 document Viewer/Alternate 及 smartzip URL scheme。

默认关联使用 [NSWorkspace 的异步设置接口](https://developer.apple.com/documentation/appkit/nsworkspace/setdefaultapplication(at:toopencontenttypeoffileat:completion:))，允许系统自身请求用户同意；候选应用注册使用 [LSRegisterURL](https://developer.apple.com/documentation/coreservices/1446350-lsregisterurl)。macOS 12 为本轮接口最低目标；Windows/Linux 管理入口明确返回未实现。

Finder Quick Action 位于用户 Library/Services，以 Automator Run Shell Script arguments 模式交给 helper。helper 向已运行应用发送认证的自定义打开事件，避免另起 GUI；普通 file URL 保持预览意图。自定义解压 URL 验证本地绝对路径、token、参数白名单和请求大小；token 存储为当前用户私有文件，不进入日志。安装与移除仅处理自身生成且内容未被修改的 workflow；不覆盖用户服务。原生菜单刷新使用 NSUpdateDynamicServices。

验证：GUI 32 项、platform 7 项、Python 打包 2 项测试通过。包括真实 Automator 临时工作流（空格/单引号路径）、读取实际默认程序状态、认证/混合意图 URL 解析、用户修改服务保护；GUI 严格 Clippy、构建、应用包签名校验和 Info.plist 校验通过。本地输出 `target/debug/bundle/SmartZip.app`。未实际切换用户默认应用或安装真实 Finder 服务；系统授权对话框与右键可见性尚未经原生 UI 验收。

## 解压失败诊断与 macOS 后端发现

用户报告的 ZIP 解压事件中候选与拒绝后端均为空、尝试列表为空，失败发生在调用后端前，不能据此认定归档损坏。本机复现：终端 PATH 能发现 Nix/Homebrew 的后端，`PATH=/usr/bin:/bin` 时旧版 doctor 返回空列表。共享 locator 现保留 bundled、PATH 优先级，并补充 macOS Homebrew/MacPorts/Nix 常见位置；验证可执行性、规范化去重，显式禁用与关闭自动发现仍生效，不修改进程 PATH 或读取 shell 初始化脚本。

路由错误区分无注册后端与能力不兼容，包含配置补救提示和原始路由诊断。GUI 从结构化路由事件生成缺少后端的中文提示；Failed/Partial 结束后保留最后失败原因，后续进度不抹除，成功与取消不显示旧失败。原始错误仍留在事件和 JSON 中。

验证：archive 68 项库测试、GUI 36 项测试、GUI 严格 Clippy、CLI/GUI 构建通过；最终产物在精简 PATH 下 doctor 发现 7-Zip，真实解压临时中文文件名 ZIP 并核对字节；独立 TOML 关闭发现后真实返回可操作的缺少后端错误。更新并签名 `target/debug/bundle/SmartZip.app`，未替换用户已安装副本。未解压或验证用户原始归档，未进行 Finder 原生视觉验收。
