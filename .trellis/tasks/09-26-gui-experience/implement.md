# GUI 桌面体验实施记录

日期：2026-09-26。已落地应用外壳、主题与主要工作流；完整发布验收尚未完成。目标和完整验收矩阵见 [prd.md](prd.md)，本文件记录实际实现与验证，不把规划项视作已交付。

## 架构与实现优先级

先完成 P0 的状态归属、草稿保护、取消退出与持久化，再完成 P1 的界面组织、管理页面与平台入口。沿用 GPUI 与共享引擎，不创建平行任务库，不复制核心提交/回滚逻辑。

- `ui/mod.rs` 管理一个 Workspace、一个原生窗口和一个 View。快速/完整模式切换改变布局，保留页面、设置表单、归档标签、目录与队列；不创建第二个窗口。显示模式恢复尺寸使用桌面偏好中的 `quick_window` / `full_window`，字段名为兼容已保存配置而保留；最大化/全屏窗口由窗口管理器控制。
- 应用菜单、右上角切换、系统打开、快速解压和通知均路由到这个窗口。创建窗口在 deferred 回调中同步完成，避免 Workspace 重入，以及连续打开请求创建多个窗口。
- 任务中心承担添加、配置、排队、进度与批量管理。归档预览有独立页面；校验与内嵌检测收在当前归档的「归档操作」菜单，原位展示最新结果，仍复用统一执行队列与交互请求。
- 原 `ui.rs` 拆分为任务、预览、待处理交互、历史、密码、设置、恢复和桌面外壳模块。后台工作通过有类型的消息回传；历史、密码、详情与显密查询带请求版本/身份，避免旧结果覆盖新页面。
- `preferences.rs` / `appearance.rs` 独立保存主题和窗口偏好，解压策略仍使用共享配置快照。`queue_store.rs` 负责等待队列，`runtime/recovery.rs` 负责用户显式选择的恢复。

## 已实现的功能

### 外壳、UI 与主题

- 跟随系统、浅色、深色；灰白/石墨色表面及蓝色强调色。同步组件颜色与 GPUI theme tokens，修复深色模式按钮残留白色背景。
- 舒适/紧凑行高、12–18 字号、减少动效、通知开关、侧栏和详情栏偏好；桌面偏好原子保存，异步写入合并，退出等待写入结束。
- 详情区域可收合，宽度可选，窄布局移到列表下方。窗口尺寸与位置恢复；恢复时检查显示器可见范围。
- 原生应用菜单与 Ctrl/Cmd 快捷键，包括打开、添加、设置、搜索、任务/历史、详情与模式切换；关于与快捷键帮助页面。
- 统一主题确认弹层，正文可换行、窄窗口自适应、危险操作不会由默认 Enter 接受，保留焦点恢复。退出、设置重新加载、密码删除/明文导出共用此入口。

### 任务与归档浏览

- 任务名称/路径搜索、状态筛选、根归档多选与批量取消/失败重试、移除已结束会话项；列表采用虚拟行，批次、根归档和嵌套节点分层显示。
- 「添加并配置」保留等待草稿，任务显式开始。新任务默认配置仍默认展开，可手动收合并记住偏好。
- 跨解压/预览队列的待处理总览，响应绑定任务与 prompt revision；切换请求清空密码输入，避免回答落到其他任务。
- 编码候选、内嵌归档信息使用可读内容；密码继续由内存传递。取消仍等待核心后端停止和清理。
- 归档目录索引缓存、虚拟条目列表、目录面包屑、当前目录搜索、名称/大小排序、复制成员路径、可关闭标签、按标签保留目录、收合成员预览。关闭归档会取消读取并释放对应缓存。
- 归档操作按当前路径执行，已有同类等待/执行任务时禁止重复发起。校验结果区分完好、确认损坏、缺卷、未知及完整/部分/未检查范围；疑似分卷组不会冒充确认损坏的卷。

### 持久化、恢复与退出

- 等待解压任务在已有 `tasks` 表中使用 `queued_gui` 状态保存顺序、稳定 TaskId 和完整配置快照；没有新增 schema 或第二套任务库。临时密码字段跳过序列化。
- 最新快照写入成功后才允许启动，包括手动「立即开始」。只读/关闭状态存储时维持会话内队列，不承诺重启恢复。
- 引擎提交以事务接管 `queued_gui` 记录并插入节点；条件更新防止迟到保存/取消覆盖已执行状态。重跑解压分配新 TaskId，恢复保留旧 TaskId。
- 启动只读检查待恢复记录；等待草稿重启后保持待开始，冻结原配置，并说明临时密码需重新输入。新建解压不再偷偷运行其他历史任务。
- 「恢复此任务」只领取指定历史任务，沿用执行所有权锁和原始计划，在失败前置检查后仍允许重试。恢复文件中心先补入已提交根归档，保留父成功/子失败的部分成功语义。
- 退出使用明确状态：继续使用、取消并清理后退出；只有没有正在执行工作且可持久化时才提供保存等待队列。保存失败可重试，也可明确接受队列变更丢失后退出，避免应用无法退出。

### 历史、密码、设置和系统入口

- 历史和密码查询改为参数化搜索及每页 50 条分页。历史提供结构化文件/事件、原始输入重跑、输出定位/缺失时复制路径、诊断导出。
- 密码列表只查询元数据；批量置顶、启停、删除；显密响应按请求身份校验；清理先查看候选数量再确认，写入时重新排除置顶项；明文导出显式确认。
- 设置支持搜索和修改数量，保留表单草稿；保存期间禁止继续编辑，失败保留修改。后端安装列表、密码来源顺序改为结构化编辑；加入保存配置的后台后端诊断。
- Unix 单实例通过账户私有目录、锁与有界本地消息转发打开请求，保留非 UTF-8 路径字节；新请求定位当前窗口模式。
- Linux 增加用户级 `.desktop` 注册、QuickExtract 动作和默认 MIME 关联入口，正确转义 Exec 参数；系统集成页面按平台显示文案。注册和更改默认关联均为显式用户动作。
- 按任务状态聚合系统通知，点击定位任务中心。未以实际系统通知点击验收来替代实现证据。
