# UI font

`NotoSansCJKsc-Regular.otf` is the unmodified static Regular face from
[Noto CJK Sans 2.004](https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/OTF/SimplifiedChinese).
It is embedded to keep Chinese/Latin interface text readable and consistent across
platform font installations. License: SIL Open Font License 1.1 (`OFL.txt`).

Source: https://raw.githubusercontent.com/notofonts/noto-cjk/Sans2.004/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
